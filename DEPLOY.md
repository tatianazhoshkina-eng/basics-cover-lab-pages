# Deployment

This directory is a standalone static GitHub Pages project.

1. Create a GitHub repository for the team-approved visibility level.
2. Push this directory to the repository's `main` branch.
3. In **Settings → Pages**, set **Source** to **GitHub Actions**.
4. The included workflow publishes `index.html`, the media library, fonts, and local assets.

The page stores saved variants in each browser's local storage. Use **Экспорт проекта** / **Импорт проекта** to hand work between devices. Use **ZIP для агента** only after checking the production progress and missing-slot warning.
